# Streamiverse Hub

## Overview

Streamiverse Hub is a premium streaming platform built with React and TypeScript, designed to deliver a seamless entertainment experience. The platform offers a curated selection of movies, series, and exclusive content with an intuitive user interface.

## Features

- **Responsive Design**: Optimized viewing experience across all devices
- **Content Discovery**: Browse through categories and trending content
- **Personalized Library**: Create and manage your watchlist with "My List" feature
- **Video Playback**: Smooth streaming with advanced player controls
- **User Management**: Profile customization and viewing history tracking
- **Notifications**: Real-time alerts for new content and recommendations

## Tech Stack

- **Frontend**: React 18+ with TypeScript
- **Styling**: Tailwind CSS with custom components
- **Build Tool**: Vite
- **UI Components**: shadcn/ui
- **Testing**: Vitest

## Getting Started

### Prerequisites
- Node.js 16+
- Bun package manager

### Installation

```bash
bun install
```

### Development

```bash
bun dev
```

The app will be available at `http://localhost:8080`

### Build

```bash
bun run build
```

## Project Structure

- `/src/components` - Reusable React components
- `/src/pages` - Main application pages
- `/src/hooks` - Custom React hooks
- `/src/lib` - Utility functions and data
